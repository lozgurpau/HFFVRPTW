# HFFVRPTW Benchmark Instances and Best Solutions

This repository provides supplementary materials for the paper **“Departure-time-aware optimization of a heterogeneous fixed-fleet vehicle routing problem for automotive inbound logistics.”**

## Contents

- **[Online Resource 1](Online_Resource_1.zip):** The 24 benchmark instance files for the Heterogeneous Fixed-Fleet Vehicle Routing Problem with Time Windows (HFFVRPTW). The instances cover six classes (R1, R2, C1, C2, RC1, and RC2), with four instances per class. Each instance has 100 customers, one depot, and a fixed heterogeneous fleet. The ZIP archive also includes a description of the tab-separated instance format.
- **[Online Resource 2](Online_Resource_2.xlsx):** The best solutions obtained for all 24 instances under five configurations: time-based (HT), distance-based (HD), FIXED-PENALTY, SOFT, and MULTILEVEL (120 cases in total). The **Best solutions** worksheet reports objective values, and the **Routes** worksheet lists the vehicle types and customer sequences for each route. In each sequence, `0` denotes the depot.

The benchmark instances are based on the HFFVRPTW adaptation by Paraskevopoulos et al. (2008) of the Liu and Shen (1999) instances derived from Solomon (1987). For example, `r101_A1.txt` corresponds to instance **R101A** in the results.
